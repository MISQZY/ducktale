## Authorization

<Callout variant="tip" title="Licensed copy">
  If you're playing a licensed copy of Minecraft, you can skip this section. Authorization happens automatically.
</Callout>

On your first login with a **cracked** copy of the game, the server will ask you to register:

```
/register <Password> <Repeat password>
```

<Callout variant="warning">
  Remember your password — you'll need it every time you log in to the server.
</Callout>

On subsequent logins, use:

```
/login <Password>
```
