---
title: Player Roles
description: Player roles on the DuckBurg server
---

The server has several roles that reflect a player's status and contribution to the project.

| Role | How to get it | Description |
|------|-------------|----------|
| **Player** | Automatically on joining | The base role for all new players. |
| **Old-timer** | By staff decision or during events | Given to experienced players who've been part of the project for a long time. |
| **Sponsor** | Total donations of **777 ₽** or more | A role for players who've supported the server's development financially. |
| **Media** | By application, if you have an audience | For streamers and content creators covering server life. |

<Callout variant="tip" title="Sponsor">
  The Sponsor role grants a number of perks — access to unique commands and cosmetics. Check the staff for the current list.
</Callout>

<Callout variant="info" title="Media">
  Media players can invite new players for free. If you stream, reach out to staff.
</Callout>
