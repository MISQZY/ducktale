### How to read the tree

- **No lock icon** — the objective is already available to start.
- **A line between nodes** — a condition link: the node on the right requires the one on the left to be done (or a tag it sets).
- Each node's title and description come from the server's NPC dialogue and objective name — if something looks like a plain formatted key rather than a nice title, that objective doesn't have human-readable dialogue text attached yet.
